## 当前主页视觉基准（V1.4 桌面 / V1.5 手机）

V1.4.0 作为当前主页视觉定稿基准。后续新增功能时，除非明确要求重新设计主页，否则优先保持这套视觉结构：

- 背景保持蓝色天空方向，使用较多低矮横向云，云从右往左飘。
- 主页主体保持固定 `2400 x 1200` 的 2:1 设计画布，外层整体等比例缩放；不同桌面窗口尺寸下，应让整张项目地图一起缩放，不要让内部字体、卡片、间距各自重排变形。
- 保持四区地图骨架：左上项目区、右上施工中、左下怪念头、右下频道入口区，蓝色分割线和外框比例不随意调整。
- 项目区保持三列：两张竖向大卡片 + 右侧三张横向卡片；大卡片、横卡、标题、图标、按钮和状态标签按当前比例维护，不再只微调单个字号导致整体比例漂移。
- 项目卡片圆角、玻璃感、阴影、白色卡片质感、右侧待办条和右下频道条的宽度节奏以当前版本为准。
- 大项目卡片链接按钮不显示右箭头，避免网址文本拥挤。
- 怪念头区保持漂浮标签风格：碰撞范围、标签不换行、随机大小和物理碰撞参数以 V1.4.0 为基准；后续只在明确反馈下微调。
- 首屏加载进度条、延后启动念头物理动画和 Canvas 云层的性能策略保持不变。
- V1.4.3 起右上标题显示为“施工中”，左下标题显示为“怪念头”；右下频道入口条更矮，怪念头碰撞上下边界保持同样外扩，横向空白项目卡标题略小。
- V1.4.4 起后台保存会绑定打开编辑台时的线上 revision；如果线上内容已变化，旧编辑台不能直接覆盖保存。
- V1.5 起手机端新增竖版长卷轴布局：项目区、施工中、怪念头、自媒体入口按顺序纵向展示；桌面端仍保持 V1.4 固定 2400 x 1200 横版项目地图与整体等比缩放规则。
- V1.5.1 起手机端关闭云层背景动画，项目卡片图标缩小，怪念头运动数量和速度下调，优先改善手机端流畅度。
- V1.5.2 起手机端项目大卡移除大图标，标题放大并改为更紧凑的偏横向排布；怪念头区高度放大，手机端初始可见念头恢复为 7 个，自媒体标题下划线隐藏。
- V1.5.3 起手机端项目卡片描述不再被状态标签挤窄，卡片内部竖向间距收紧；空白项目卡片采用和已有项目卡一致的手机端结构，自媒体标题下划线恢复到标题下方。

如果未来要做 3D 项目轮、留言区、账号系统等新方向，先保护这个 V1.4 主页基准，再单独规划新模块。

## 内容编辑台

V1.2 新增静态编辑台：

```txt
https://鸦珉.icu/admin
```

本地预览：

```txt
http://127.0.0.1:4173/admin
```

当前编辑台负责编辑草稿、预览、导出数据文件，并在配置保存口令后写入线上网站。

V1.25 起新增 `/api/site-data` 数据接口：

- 本地预览没有数据库配置时，保存到 `data/site-data.local.json`。
- 线上部署时，通过 Supabase REST API 写入数据库。
- Supabase 建表脚本在 `supabase/site_pages.sql`。
- Vercel 需要配置：
  - `SUPABASE_URL`
  - `SUPABASE_SERVICE_ROLE_KEY`
  - `SITE_ADMIN_TOKEN`
  - `SITE_DATA_TABLE`（可选，默认 `site_pages`）
  - `SITE_DATA_BACKUP_TABLE`（可选，默认 `site_page_backups`）
  - `SITE_DATA_ID`（可选，默认 `homepage-v1`）
  - `CRON_SECRET`（用于每周自动备份接口授权）

`SUPABASE_SERVICE_ROLE_KEY` 只放在 Vercel 环境变量里，不能放到浏览器端代码里。

V1.4.1 起新增后台数据安全规则：

- 后台编辑台如果没有读到线上数据库，只读到静态旧数据，会禁止直接保存，避免旧内容覆盖线上数据。
- 线上保存前会先把当前数据库内容写入 `site_page_backups`，保存后再写入一份新快照。
- `/api/site-data-backup` 可用于手动或定时备份当前线上内容。
- `vercel.json` 配置每周自动调用一次 `/api/site-data-backup`，生产环境需要设置 `CRON_SECRET`。

V1.4.2 起新增后台会话规则：

- 后台保存不再把口令或口令哈希存入 `localStorage`。
- 输入后台口令后，服务器发放 HttpOnly cookie；普通设备默认 3 小时有效。
- 授权弹窗可勾选“信任这台设备”，可信设备会话 180 天有效，并在打开后台或保存时自动续期。
- 服务端只在 `admin_sessions` 表保存 session token 的哈希、过期时间和可信设备标记。
- 会话过期后再次保存会提示重新输入口令，当前草稿不会丢。

V1.27 调整后台编辑体验：
- 修复项目卡片、待办横条的上移 / 下移排序。
- 待办横条增加黄、青、黑、白等颜色，并把红色改为更明确的大红。
- 奇怪念头编辑项改为紧凑标签式，只保留文本、显示开关和删除。

V1.28 调整主页待办区：
- 待办区改为标题 + 内部列表布局。
- 6 条待办可以正常显示在右上模块内。
- 超过可用高度时只在待办列表内部滚动，不挤压右下账号区。

V1.29 调整主页项目区：

V1.31 修正待办区：
- 白色待办标签的进度条改为浅白底轨 + 白色高亮填充，避免显示成灰色进度条。
V1.32 修正待办区：
- 白色待办标签不再使用单独的浅白轨道样式。
- 待办进度条统一为淡蓝底轨，进度填充跟随标签颜色。
V1.33 调整奇怪念头区：
- 奇怪念头标签颜色改为前台自动洗牌分配，不再依赖后台数据中的固定颜色。
- 即使后台新增念头默认颜色都是蓝色，前台也会尽量均匀分布为多种颜色。
- 后台保存念头时不再记录颜色字段，颜色只作为每次展示时生成的临时状态。
V1.34 调整页面文案与奇怪念头区：
- 浏览器标题去掉 `V1`，显示为“鸦珉.icu - 项目地图”。
- 站点签名副标题改为“一张不太正经的项目地图”。
- 奇怪念头空间的碰撞区域向上下和横向扩大，让标签活动范围更接近底部区域。
V1.35 调整奇怪念头区：
- 奇怪念头标签的边界反弹安全距离从 `8px` 增加到 `40px`。
- 标签和阴影会在接近碰撞边缘前反弹；空间较窄时会自动取可用的最大安全距离，避免阴影被裁切后显出边界感。
V1.36 修正手机端内容空白：
- 首页公共脚本去掉 `replaceAll`、`??`、`?.`、`catch {}` 等旧手机浏览器容易不兼容的写法。
- 页面会先填充项目、待办、念头和频道内容，再尝试启动云层 Canvas 动画；云层失败不会再阻断内容显示。
- 根页面增加 `nomodule` 兜底，不支持模块脚本的浏览器会进入带静态内容的 `/v1/` 页面。
V1.37 调整奇怪念头区：
- 奇怪念头碰撞空间扩大到接近左下区域整块宽度，从左侧较近位置开始，到右侧边界前结束。
- 奇怪念头区标题上移一点，并保持在念头标签上方，避免标签经过时压住标题。
V1.38 继续扩大奇怪念头区：

- 奇怪念头区标题再上移一点，给标签运动留出更多低区空间。
V1.39 微调奇怪念头区：
- 奇怪念头碰撞空间继续向上下贴近面板边缘，进一步扩大标签活动范围。
- 奇怪念头区标题回到 V1.37 的位置，不再继续上移。
- 页面刷新时奇怪念头初始只随机显示 5-6 个，之后在这个数量附近慢慢出现或消失。
V1.3.10 调整频道入口与版本命名：
- 右下角频道入口标签改为跟右上角待办横条一致的宽度节奏，减少底部标签偏长的突兀感。
- 当前小版本命名改为三段式 `V1.3.10`，后续用 `主版本.功能阶段.小版本序号` 记录。
V1.3.11 调整移动端性能与念头数量：
- 奇怪念头初始可见数量从 5-6 个提高到 7-8 个。
- 手机和低性能设备不再启动重 Canvas 云层，改用现有 SVG 云层兜底，避免页面加载后卡住。
- 根页面增加模块脚本兜底跳转，模块内容未填充时自动进入带静态内容的 `/v1/`。

V1.3.12 调整首屏加载与性能：
- 浏览器标题改为 `鸦珉.icu`，去掉标题里的“项目地图”后缀。
- 首页增加轻量顶部进度条，用于提示本地内容、线上数据和动画启动的加载阶段。
- 线上数据请求设置短超时，念头物理动画和 Canvas 云层延后到内容出现后再启动；手机和低性能设备不再运行念头物理动画。

V1.4.0 主页视觉定稿：
- 主页升级为固定 2:1 设计画布 + 外层整体等比例缩放，桌面小窗口下不再让内部卡片和文字独立挤压变形。
- 项目区、待办区、频道入口、奇怪念头区完成多轮比例微调，当前视觉作为后续版本基准。
- 奇怪念头区修正小窗口碰撞范围、右边界文字换行、活动边界和随机大小，保持更自然的漂浮碰撞感。
- 新增 V1.4 视觉基准说明，后续非重设计任务不要轻易改动主页骨架、卡片比例和核心动效参数。

V1.4.1 后台保存保护与数据备份：
- 后台读不到线上数据库时禁止保存，避免静态旧数据覆盖线上。
- 每次线上保存前后写入 `site_page_backups`。
- 新增每周备份接口和 Vercel Cron 配置。

V1.4.2 后台会话与可信设备：
- 后台口令不再存入 `localStorage`。
- 普通设备会话 3 小时，可信设备会话 180 天。
- 服务端只保存 session token 哈希和过期时间。

V1.4.3 主页小调：
- 右上标题改为“施工中”，左下标题改为“怪念头”。
- 怪念头碰撞上边界向上扩展，并与下边界保持同样外扩量；右下频道入口条再变矮。
- 项目区横向空白卡片标题字号小 1px。

V1.4.4 后台编辑基准版本校验：
- `/api/site-data` 读取内容时返回当前数据 revision。
- 后台保存线上内容时提交打开编辑台时的 `expectedRevision`；服务器发现 revision 不一致时返回冲突并停止写库。
- 后台新增“查看主页”入口，使用新标签打开主页，减少通过浏览器后退来回切换导致旧状态保存的风险。
- 后台从浏览器历史缓存恢复时会重新检查线上 revision；发现旧版本时保留当前草稿并禁止直接覆盖。
