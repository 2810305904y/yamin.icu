## 内容编辑台

V1.2 新增静态编辑台：

```txt
https://鸦珉.icu/admin
```

本地预览：

```txt
http://127.0.0.1:4173/admin
```

当前编辑台只负责编辑草稿、预览和导出数据文件。它还不能直接写入线上网站。

V1.25 起新增 `/api/site-data` 数据接口：

- 本地预览没有数据库配置时，保存到 `data/site-data.local.json`。
- 线上部署时，通过 Supabase REST API 写入数据库。
- Supabase 建表脚本在 `supabase/site_pages.sql`。
- Vercel 需要配置：
  - `SUPABASE_URL`
  - `SUPABASE_SERVICE_ROLE_KEY`
  - `SITE_ADMIN_TOKEN`
  - `SITE_DATA_TABLE`（可选，默认 `site_pages`）
  - `SITE_DATA_ID`（可选，默认 `homepage-v1`）

`SUPABASE_SERVICE_ROLE_KEY` 只放在 Vercel 环境变量里，不能放到浏览器端代码里。

V1.27 调整后台编辑体验：
- 修复项目卡片、待办横条的上移 / 下移排序。
- 待办横条增加黄、青、黑、白等颜色，并把红色改为更明确的大红。
- 奇怪念头编辑项改为紧凑标签式，只保留文本、显示开关和删除。

V1.28 调整主页待办区：
- 待办区改为标题 + 内部列表布局。
- 6 条待办可以正常显示在右上模块内。
- 超过可用高度时只在待办列表内部滚动，不挤压右下账号区。

V1.29 调整主页项目区：
- 项目区前两张大卡列宽略微收窄。
- 右侧横向项目卡列略微放宽，让项目区比例更轻。

V1.30 调整奇怪念头区：
- 奇怪念头从固定位置标签升级为“念头空间”。
- 标签拥有随机大小、随机初始位置、随机速度和方向。
- 标签在空间内边界反弹，彼此碰撞后弹开。
- 标签每隔 3 到 5 秒随机出现或隐藏；隐藏后不参与碰撞。
V1.31 修正待办区：
- 白色待办标签的进度条改为浅白底轨 + 白色高亮填充，避免显示成灰色进度条。
V1.32 修正待办区：
- 白色待办标签不再使用单独的浅白轨道样式。
- 待办进度条统一为淡蓝底轨，进度填充跟随标签颜色。
V1.33 调整奇怪念头区：
- 奇怪念头标签颜色改为前台自动洗牌分配，不再依赖后台数据中的固定颜色。
- 即使后台新增念头默认颜色都是蓝色，前台也会尽量均匀分布为多种颜色。
- 后台保存念头时不再记录颜色字段，颜色只作为每次展示时生成的临时状态。
