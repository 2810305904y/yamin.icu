# 鸦珉.icu 个人主页

当前版本：V1.1 草稿  
项目定位：个人主页 / 项目地图 / 公开频道入口

## 线上地址

Vercel 地址：

```txt
https://yamin-icu.vercel.app/
```

自定义域名：

```txt
https://鸦珉.icu/
```

后台配置时使用：

```txt
xn--idyr71g.icu
```

## 本地查看

```txt
npm.cmd run preview
```

默认打开：

```txt
http://127.0.0.1:4173/
```

当前对话里也可能使用临时预览地址：

```txt
http://127.0.0.1:4181/
```

## 修改内容

内容数据先维护在：

```txt
v1/content/site-data.mjs
```

里面包含：

- 项目区卡片。
- 正在进行 / 待办区。
- 奇怪念头区。
- 自媒体与视频账号入口。
- 左下角站点签名。

## 内容编辑台

V1.2 新增静态编辑台：

```txt
https://鸦珉.icu/admin
```

```txt
http://127.0.0.1:4173/admin
```

当前编辑台只负责编辑草稿、预览和导出数据文件。它还不能直接写入线上网站。
