# V1.4.2 后台会话与可信设备

记录日期：2026-06-03

## 背景

后台编辑需要在手机、临时电脑和主电脑之间取得平衡：临时设备不应长期保留编辑权限，主电脑又不希望频繁输入口令。

## 本次调整

- 新增 `/api/admin-session` 后台会话接口。
- 后台保存口令不再写入 `localStorage`。
- 服务器登录成功后设置 HttpOnly cookie。
- 普通设备会话默认 3 小时有效。
- 授权弹窗新增“信任这台设备”选项。
- 可信设备会话 180 天有效，打开后台或保存时自动续期。
- 服务端在 `admin_sessions` 表只保存 session token 的哈希、过期时间、是否可信和最后使用时间。
- 会话过期后再次保存会重新弹出授权框，当前草稿不丢失，授权后继续保存。

## 数据表

新增 `public.admin_sessions`：

- `token_hash`：session token 的 SHA-256 哈希。
- `trusted`：是否为可信设备。
- `expires_at`：过期时间。
- `revoked_at`：清除此设备授权时写入。
