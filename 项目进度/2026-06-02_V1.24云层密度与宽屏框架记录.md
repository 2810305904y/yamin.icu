# V1.24 云层密度与宽屏框架记录

文档版本：V1.0  
整理日期：2026-06-02  
所属阶段：V1.2

## 本轮定位

本轮仍属于 V1.2 阶段内的小更新，核心不是新增栏目，而是继续打磨首页的视觉底层：

- 背景云层更丰富。
- 云层移动速度略快。
- 主页外框恢复成更接近宽屏铺开的状态。
- 小屏幕时尽量不再把版面压扁。
- 本地预览服务重新启动，方便继续看效果。

这次改动还没有推送到 GitHub / Vercel。

## 已完成改动

### 1. 云层数量增加

当前 Canvas 云层从上一版的较稀疏状态增加到 29 组云。

调整思路：

- 保留当前比较认可的低矮横向云形。
- 新增更多中小云，填补上半区、右侧、右下区等空白位置。
- 新增云的透明度整体偏低，避免抢项目卡片和文字的注意力。
- 继续避免之前那种“底部凹进去一块”的云形。

相关文件：

```txt
v1/scripts/render-site.mjs
```

### 2. 云层速度加快

Canvas 云层移动速度从：

```txt
0.012
```

调整为：

```txt
0.02
```

备用 SVG 背景动画也同步从：

```txt
118s
```

调整为：

```txt
82s
```

这样主背景和备用背景在体感上不会差太多。

相关文件：

```txt
v1/scripts/render-site.mjs
v1/styles.css
```

### 3. 外框尺寸恢复为宽屏优先

之前为了处理小尺寸屏幕，把外框锁成过于保守的比例，导致 2K 宽屏下看起来像被缩小了。

本轮修正为：

```txt
最大宽度：2400px
宽高比例：2.1 / 1
宽度计算：min(2400px, calc(100vw - 28px), calc((100vh - 28px) * 2.1))
```

效果目标：

- 在宽屏上尽量铺开。
- 在高度不够时仍然按比例收缩，避免明显压扁。
- 不再被 1920px 上限卡住。

相关文件：

```txt
v1/styles.css
v1/tests/admin.test.mjs
```

```txt
/v1/scripts/render-site.mjs?v=1.24-cloud-more-c
```

相关文件：

