# 2026-06-02 V1.27 后台编辑控件与待办颜色记录

## 版本定位

V1.27 是 V1.2 阶段的小修复版本，重点是让内容编辑台更适合实际维护主页数据。

## 本次确定内容

- 修复后台项目卡片、待办横条的上移 / 下移排序逻辑。
- 后台排序后会重新写入 `order`，避免界面刷新后又回到旧顺序。
- 待办横条颜色扩展为：`blue`、`green`、`orange`、`purple`、`pink`、`red`、`yellow`、`cyan`、`black`、`white`。
- `red` 改为更明确的大红 `#ff0000`。
- 待办横条的进度线跟随当前颜色，不再固定为蓝色。
- 奇怪念头编辑项改为紧凑标签式，只保留文本、显示开关和删除按钮。
- 奇怪念头暂时不提供上移 / 下移；后续可继续发展为随机出现、随机消失、随机大小的标签区域。

## 验证

- `npm.cmd run check` 已通过。
- 本地后台验证：
  - 项目卡片点击上移后顺序改变。
  - 待办横条点击上移后顺序改变。
  - 奇怪念头没有上移 / 下移按钮。
  - 待办颜色下拉包含黑、白、黄、青等新增颜色。
