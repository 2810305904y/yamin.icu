## 已完成

- Vercel 已创建独立测试项目：`yamin-icu-test`。
- 当前代码已部署到测试项目，测试服目标返回 `V1.6.24` 页面。
- `test.xn--idyr71g.icu` 已添加并绑定到测试项目。
- 正式测试域名 `https://test.xn--idyr71g.icu/` 已验证可访问。
- 本地 `.vercel` 链接已恢复到主站项目：`yamin-icu`。
- 测试项目已配置只读 Supabase 环境变量，用于读取正式服页面数据；不配置可写 Supabase 环境变量。
- 测试服 `/admin` 已禁用“保存到线上”；后端 `/api/site-data` 在测试服域名下也会拒绝写入。
- 测试服没有数据库环境变量时，主页数据接口会返回静态回退数据并显示读取失败提示，不再读取本地草稿文件。
- V1.5.9 起，测试服触发静态回退时会把云背景替换为 `THIS IS FINE` 表情包背景；桌面端滚动，手机端静态。
- V1.6.0 起，测试服首页打开时先显示全屏读取层；关键内容渲染完成后显示“读取完成”，再露出主页。
- V1.6.1 起，测试服静态回退时读取层显示“读取失败，显示备用页面”，进度条停在未满格状态，不再显示“读取完成”。
- V1.6.2 起，测试服静态回退时会先保留 4 秒“正在读取项目地图”，进度条线性推进到约 82%，然后再显示读取失败提示。
- V1.6.3 起，读取失败提示出现后的停留时间缩短，备用主页更快露出。
- V1.6.4 起，真实读取成功进入完成状态时会取消兜底动画，避免成功后继续等待约 7 秒才露出主页。
- V1.6.5 起，读取失败进入备用主页时保留约 1 秒淡出过渡，读取框内站名继续放大。
- V1.6.6 起，读取失败淡出会等待完整动画结束后再移除遮罩，避免淡出刚开始就被隐藏。
- V1.6.7 起，读取失败进入 `exiting` 独立淡出阶段，淡出阶段保持可见，结束后才进入 `done` 隐藏状态。
- V1.6.8 起，读取失败退出使用显式 keyframes 动画，避免旧兜底动画切换到 transition 时直接跳到透明终点。
- V1.6.9 起，读取成功会保留 1.5 秒“读取完成”状态，加载框站名放大并收紧与标题的排版间距。
- V1.6.10 起，加载框站名和标题字号回到初始大小，只保留更紧行距；读取失败提示停留 2 秒后再淡出。
- V1.6.11 起，读取成功显示“读取完成”0.5 秒后进入 1.5 秒淡出；加载框站名进一步缩小并压紧间距。
- V1.6.12 起，加载框站名继续缩小；读取标题与进度条之间增加距离，让标题更靠上、进度条更松。
- V1.6.13 起，云层 Canvas 在加载遮罩下提前启动但不阻塞完成判断；主页内容和怪念头会在遮罩下准备完成后再淡出。
- V1.6.14 起，加载进度条首秒平滑推进到约 40%，随后继续推进到 82%，避免读取成功时从低进度直接跳到满格。
- V1.6.15 起，根页面不再因为项目区短时间为空而自动跳到 `/v1/`，只保留 `nomodule` 旧浏览器兜底。
- V1.6.16 起，测试服可以读取正式服 Supabase 页面数据，但保存和备份仍按测试服规则拒绝写入。
- V1.6.17 起，加载遮罩初始状态就是读取中，进度条不等脚本切换状态；失败路径在 3 秒内推进到 60%，第 4 秒再显示失败提示。
- V1.6.18 起，加载进度条改成 3 秒匀速从 8% 推进到 60%，减少第一秒过快和中段卡顿感。
- V1.6.19 起，读取成功时也按遮罩实际可见后的时间等待进度条跑满 3 秒，再显示读取完成，避免成功路径停在低进度后直接跳转。
- V1.6.20 起，读取成功不再强制等待 3 秒；成功后锁定当前进度并立即平滑补到 100%，减少成功路径的低进度停顿。
- V1.6.21 起，Canvas 云层延后到加载遮罩结束后再通过空闲任务启动，避免加载中读条被云层纹理生成阻塞。
- V1.6.22 起，数据读取仍然从第 0 秒开始，Canvas 云层在遮罩出现后的第 2 秒开始安排启动；成功路径等待云层准备完再显示读取完成，失败路径跳过云层。
- V1.6.23 起，测试服 `/fail` 会强制首页读取失败，用于验证读取失败提示、备用页面和淡出效果；普通测试服首页仍读取只读 Supabase 数据。
- V1.6.24 起，加载文案使用固定三秒时间轴；普通首页成功读取后才进入“正在绘制棉花糖”，`/fail` 仍用于强制失败验证。

## 后续测试服部署顺序

临时把本地目录指向测试项目：

```txt
npx.cmd vercel link --yes --project yamin-icu-test --scope ravenous-projects-47c09001
```

部署到测试项目：

```txt
npx.cmd vercel --prod --yes --scope ravenous-projects-47c09001
```

部署后必须把本地目录重新指回主站项目：

```txt
npx.cmd vercel link --yes --project yamin-icu --scope ravenous-projects-47c09001
```
