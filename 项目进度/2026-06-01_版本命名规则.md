# 版本命名规则

文档版本：V1.0
整理日期：2026-06-01

## 核心逻辑

本项目的版本号不是严格的软件语义化版本，而是为了方便协作和记录项目阶段。

当前规则：

```txt
V1     -> 第一版可上线个人主页
V1.1   -> V1 上线后的内容、链接、部署修正
V1.2   -> 当前阶段：后台编辑工具 + 云层背景 + 内容维护流程
V1.21  -> V1.2 阶段内的小迭代
V1.22  -> V1.2 阶段内的小迭代
V1.23  -> V1.2 阶段内的小迭代
V1.3   -> 下一个较明确的新阶段
V2     -> 大结构升级，例如 3D 项目轮
```

## V1.2 阶段的范围

`V1.2` 是一个阶段，不是一版已经完全结束的页面。

V1.2 阶段内包含：

- `/admin` 后台编辑工具雏形。
- 项目、待办、奇怪念头、频道入口的可编辑流程。
- 首页云层背景。
- 背景实验模式，例如 `?bg=1`。
- 让内容更新变得更容易的工作流。

所以 `V1.21`、`V1.22`、`V1.23` 都可以理解为：

```txt
V1.2 阶段里的第 1 次、第 2 次、第 3 次小更新
```

## 什么时候进入 V1.3

只有当功能范围明显换阶段时，才进入 `V1.3`。

例如：

- 后台编辑工具从“导出文件”升级成“点保存就能更新线上内容”。
- 接入账号登录、数据库或 GitHub 自动写入。
- 首页信息结构有明显变化。
- 反馈通道、Resend 或留言区进入正式可用状态。

## 文档记录方式

- 阶段文档可以叫 `V1.2...`。
- 阶段内小更新可以叫 `V1.21...`、`V1.22...`、`V1.23...`。
- 如果某次只是很小的视觉或文案微调，也可以只记录在对应阶段文档里，不一定单独开新文件。
- `AGENTS.md` 和 `Memory.md` 只记录长期工作习惯，不记录这种项目历史。
