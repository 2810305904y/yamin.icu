# V1.6.22 云层 Canvas 第二秒启动

日期：2026-06-08

## 目标

在保留进度条前段流畅感的同时，让 Canvas 云层更早在加载遮罩下准备，不必等遮罩完全结束后才绘制。

## 调整

- 数据读取仍然在页面打开后立刻开始，不等待 2 秒。
- 加载遮罩出现后的第 2 秒开始安排 Canvas 云层绘制。
- Canvas 启动使用空闲任务，最多等待约 600ms；不支持空闲任务时用下一帧启动。
- 如果读取成功很早返回，主页内容先在遮罩下准备，然后等第 2 秒的云层准备完成后再显示“读取完成”。
- 如果读取失败或进入备用页面，Canvas 云层会被跳过或移除，备用页继续使用失败背景。

## 状态

- 本地代码已更新为 V1.6.22。
- 测试服已部署验证：页面返回 `1.6.22-loading-canvas-second`，脚本包含 `LOADING_CANVAS_START_DELAY = 2000`，测试服 API 继续读取 Supabase 且写入返回 403。
