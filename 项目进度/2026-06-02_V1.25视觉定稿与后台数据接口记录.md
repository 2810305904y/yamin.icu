# V1.25 视觉定稿与后台数据接口记录

文档版本：V1.0  
整理日期：2026-06-02  
所属阶段：V1.2  
当前小版本建议名：V1.25

## 本轮定位

本轮是 V1.2 阶段内的小版本更新，重点是确认首页当前视觉方向，并把后台编辑工具推进到“可保存数据接口已接入”的阶段。

## 已确认的视觉方向

- 蓝色天空背景方向保留。
- 低矮横向云层方向保留。
- 云层从右往左飘，速度保持当前略快版本。
- 首页外框不再继续铺满宽屏，改为更克制的 2:1 比例。
- 手机端暂不做降级处理。

## 已完成改动

### 1. 外框比例收回

首页外框从上一版的 `2.1 / 1` 调整为：

```txt
aspect-ratio: 2 / 1
width: min(2400px, calc(100vw - 28px), calc((100vh - 28px) * 2))
```

目标是接近用户确认的第一张截图比例，保留宽屏观感，但避免“吃满屏”。

### 2. 后台新增数据接口

新增：

```txt
/api/site-data
```

能力：

- 首页优先从接口读取站点数据。
- 接口不可用时，首页回退到静态 `site-data.mjs`。
- 后台新增“保存到线上”按钮。
- 本地预览没有数据库配置时，保存到 `data/site-data.local.json`。
- 线上配置 Supabase 后，通过 Vercel API 写入 Supabase。

### 3. Supabase 建表脚本

新增：

```txt
supabase/site_pages.sql
```

表名：

```txt
public.site_pages
```

默认数据行 ID：

```txt
homepage-v1
```

表启用 RLS，不把写权限暴露给浏览器端。线上写入由 Vercel API 使用 Supabase service role 完成。

## 当前后台状态

后台已经从“只能保存浏览器草稿 / 下载数据文件”，推进到：

- 本地可以实际保存并刷新主页查看。
- 线上代码路径已准备好。
- 真正线上数据库写入还需要确认 Supabase 项目，并在 Vercel 配置环境变量。

还不算完整功能完成。完整完成标准是：

- Supabase 项目确认并执行建表 SQL。
- Vercel 配置 `SUPABASE_URL`、`SUPABASE_SERVICE_ROLE_KEY`、`SITE_ADMIN_TOKEN`。
- `/admin` 在线上可以直接保存并更新主页信息。
