# UI 参考与三版视觉方向草稿

文档版本：草稿 V0.1  
整理日期：2026-06-01  
参考站点：`https://uupm.cc/`

## 参考站点可借鉴的部分

`uupm.cc` 的 demo 不是完全拆分式布局，更接近传统 landing page：首屏大标题、右侧展示图、下方功能/价格/证明模块。但它有几个适合借鉴的点：

- 卡片有明确层级，访客一眼能知道哪里可以点击。
- 状态标签、小浮层、按钮、描边和阴影让页面有“正在运行”的感觉。
- 字体比较粗，标题有存在感。
- 颜色干净，蓝色、绿色、橙色这类状态色分工清楚。
- 圆角卡片和轻微玻璃质感可以让页面不那么硬。

不建议照搬的部分：

- 不做“公司官网式大 hero + 价值主张 + CTA”。
- 不做完整营销长页。
- 不把项目解释成商业卖点。
- 不让视觉炫技盖过项目入口。

## 方案 A：蓝图分区

关键词：

```txt
浅色、天蓝、清楚分区、像一张项目地图
```

结构：

- 保留用户手绘的四象限。
- 使用浅蓝或白色背景。
- 用蓝色细线或中等粗线划分区域。
- 项目区占左上最大面积。
- 待办区在右上，使用横条任务列表。
- 自媒体区在右下，使用图标按钮或短链接。
- 奇怪念头区在左下，使用漂浮短句。

优点：

- 最贴合当前手绘结构。
- 信息很清楚。
- 后续改成 V2 的 3D 项目轮时，项目区可以单独替换。
- 对手机端最容易适配。

风险：

- 如果线条太重，会像后台面板。
- 如果蓝色太单一，会显得冷。

建议：

这是 V1 的首选方向。它最稳，也最符合“项目地图”的目标。

## 方案 B：漂浮卡片

关键词：

```txt
浅蓝渐变、玻璃卡片、轻微漂浮、空间感
```

结构：

- 四个分区仍然存在，但边界不完全用线切开。
- 每个区块像漂在浅蓝背景上的卡片。
- 项目卡片有更明显的层级和阴影。
- 奇怪念头可以做成随机漂浮的小胶囊。
- 页面整体比方案 A 更柔和，更像私人空间。

优点：

- 设计感更强。
- 更接近参考站里的圆角、浮层、玻璃质感。
- 比较适合“有一点怪，但不吵”的气质。

风险：

- 如果透明度和阴影没控制好，会显得虚。
- 分区感不如方案 A 强，需要靠标题和间距维持清楚。

建议：

可以作为 V1.1 或 V1 的增强方向。如果你觉得方案 A 太像结构图，可以用方案 B。

## 方案 C：夜间控制台

关键词：

```txt
深蓝、发光描边、控制台、个人实验室
```

结构：

- 深色背景。
- 天蓝色发光边框。
- 项目卡片像控制台模块。
- 待办区像系统日志。
- 自媒体区像信号入口。
- 奇怪念头像异常提示或漂浮记录。

优点：

- 记忆点最强。
- 很适合“项目地图 + 一点怪”的感觉。
- 未来接 3D 项目轮时氛围感更自然。

风险：

- 如果处理不好，会太像赛博后台或加密货币网站。
- 深色模式对中文小字可读性要求更高。
- 白天手机看可能没有浅色舒服。

建议：

适合作为一个更有个性的版本，但不建议一开始就做得太重。可以保留给 V1.5 或做成可切换夜间皮肤。

## 当前推荐

优先推荐：

```txt
方案 A 的结构 + 方案 B 的轻微玻璃卡片 + 少量方案 C 的蓝色发光细节
```

也就是：

- 仍然是一张清楚的四象限项目地图。
- 主色是天蓝和白色。
- 项目卡片有轻微玻璃感。
- 状态标签用少量绿色、橙色、蓝色区分。
- 奇怪念头可以漂浮。
- 不做传统企业官网首页。

## 用户确认的 V1 方向

用户更喜欢方案 A「蓝图分区」的结构，但希望配色和材质接近方案 B 的白色、天蓝色、浅渐变和轻微漂浮感。

关键要求：

- 网站应优先按横向页面设计，不按传统竖向 landing page 设计。
- 四块分区的比例参考用户手绘图：左侧主内容更宽，右侧为窄栏；上方区域更高，下方区域较低。
- 分区框架要保留，整体像被切成四块的项目地图。
- 项目区卡片大小和位置可以继续调整，不需要完全按当前草图固定。
- 每个区里的素材大小还可以继续试，但四块框架比例是重要参考。

当前 V1 视觉公式：

```txt
横向四分区骨架
+ 浅蓝白渐变背景
+ 蓝图式分割线
+ 轻微玻璃项目卡片
+ 少量状态色点缀
```

这版应避免滑向：

- 竖向长页面。
- 企业官网 hero。
- 过重的深色控制台。
- 项目卡片过度整齐导致页面像后台模板。

## 进一步确认的框架比例

用户确认喜欢蓝图分区方向，并希望项目区进一步扩大。

调整基线：

- 竖向分割线继续向右靠，右侧栏比上一版更窄。
- 横向分割线继续向下靠，底部区域比上一版更低。
- 项目区应成为压倒性的主区域，用来承载更多项目卡片和未来 V2 的 3D 项目轮。
- `鸦珉.icu` 不放在顶部，而是作为左下角漂浮身份块。
- 左下角身份块可以轻微遮挡奇怪念头区，遮挡不算问题，反而能形成层次。

更接近的比例参考：

```txt
左侧主区域：约 85% - 88%
右侧窄栏：约 12% - 15%
上方主区域：约 78% - 82%
下方区域：约 18% - 22%
```

其中左上项目区优先级最高。右上待办、右下频道和左下奇怪念头都服务于项目区，不与项目区抢空间。

## 分割线对齐规则

用户进一步确认更喜欢规整对齐的分割方式。

分割线规则：

- 竖向分割线应贯穿上方和下方，形成完整右侧栏。
- 横向分割线应贯穿左侧和右侧，形成完整底部栏。
- 右侧的“自媒体”区域顶部，应和左侧“奇怪念头区”顶部在同一条横线上。
- 分割线交叉点应形成清楚的十字，不做错位、断开或局部错层。
- 可以保留圆角外框，但内部主分割线要像网格一样对齐。

比例可以微调为更接近当前截图：

```txt
左侧主区域：约 79% - 82%
右侧栏：约 18% - 21%
上方主区域：约 72% - 75%
下方区域：约 25% - 28%
```

这个比例比上一版稍微给右侧和底部多一点空间，但仍然保持项目区最大。

## 左下角身份文字修正

用户进一步明确：`鸦珉.icu` 不需要做成带底板的悬浮身份块。

更准确的做法：

- 只显示文字本身。
- 文字放在左下角，浮在奇怪念头区上方。
- 可以加很轻的 135 度投影，让文字看起来微微浮起。
- 阴影不应很大，羽化也不要太大。
- 文字尺寸可以偏小，接近早期示意图里的低存在感签名。
- 不需要白色卡片底、不需要独立容器。
- 文字可以轻微遮挡奇怪念头区的一部分内容。

参考感觉：

```txt
鸦珉.icu
一张稍微不太正经的项目地图
```

这组文字应像页面签名，而不是一个按钮或卡片。

## 项目卡片布局待细化

当前项目区可以先保留 5 个卡片位：

- 2 张更大的主项目卡片。
- 2-3 张更紧凑的横向项目卡片。
- 后续根据真实项目数量继续调整。

用户当前不要求项目卡片严格按示意图定稿。卡片大小、排列、图标和说明文字都可以在下一轮继续设计。

## 蓝色色系建议

建议不要全站只用一种蓝色。可以这样分工：

```txt
背景：#F4FAFF / #EAF6FF
主蓝：#38BDF8
深蓝文字：#0F2742
边框蓝：#93C5FD
状态绿：#22C55E
待办橙：#F59E0B
计划蓝：#3B82F6
危险或提醒：#EF4444，只少量使用
```

## 下一步设计动作

1. 用户从 A / B / C 或混合版里选一个主方向。
2. 确定是否要浅色为主，深色只作为后续主题。
3. 再画一版更接近真实页面的 V1 线框。
4. 用户确认后，再开始建项目代码。
