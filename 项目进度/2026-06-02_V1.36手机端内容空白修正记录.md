# 2026-06-02 V1.36 手机端内容空白修正记录

## 版本定位

V1.36 是 V1.2 阶段的兼容性小修版本，重点处理部分手机浏览器能显示背景和分区标题，但项目卡片、待办横条、奇怪念头和频道入口为空的问题。

## 问题判断

- 手机截图中外框、云层背景、分区标题已显示，说明 HTML 和 CSS 已加载。
- 项目卡片、待办、念头和频道全部为空，说明负责填充内容的前端脚本没有执行完成。
- 当前首页根路径的内容主要依赖模块脚本渲染；旧手机浏览器如果不支持部分现代语法或云层 Canvas 初始化失败，就会出现空模块。

## 本次确定内容

- 公共渲染脚本去掉 `replaceAll`、`??`、`?.`、`catch {}` 等旧手机浏览器容易不兼容的写法。
- `mountLiveSite()` 先用内置静态数据渲染一次，再尝试读取线上数据库内容，避免接口或脚本后段问题导致首屏空白。
- 页面启动顺序调整为先渲染内容，再尝试启动云层 Canvas 背景。
- 云层 Canvas 初始化外层增加兜底，失败时不会阻断内容显示。
- 根页面增加 `nomodule` 兜底，不支持模块脚本的浏览器会进入带静态内容的 `/v1/` 页面。
- 首页与 V1 页面资源版本号更新为 `1.36-mobile-script-fallback`，避免继续使用旧脚本缓存。

## 验证

- `npm.cmd run check` 已通过：31 项测试全部通过。
- 本地 `390 x 844` 手机视口已检查：项目 `5` 条、待办 `4` 条、奇怪念头 `4` 条、频道入口 `3` 条均已渲染，控制台无错误。
