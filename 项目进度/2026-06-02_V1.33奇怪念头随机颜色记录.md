# 2026-06-02 V1.33 奇怪念头随机颜色记录

## 版本定位

V1.33 是 V1.2 阶段的视觉小修版本，重点调整奇怪念头区的标签颜色分配。

## 本次确定内容

- 奇怪念头颜色不再依赖后台数据中的 `tone` 字段。
- 后台新增念头只保存文本、显示状态和顺序，不再写入颜色字段。
- 后台保存草稿、保存到线上、下载数据文件时，会移除旧念头数据里残留的 `tone` 字段。
- 静态渲染时先按颜色表轮换，避免默认数据导致蓝色过多。
- 进入念头空间后，前台会对颜色表进行洗牌分配。
- 念头隐藏后再次出现时，会重新抽取颜色。
- 颜色池包含绿、橙、紫、粉、红、黄、青、蓝，蓝色只占其中一个普通颜色位。
- 首页与 V1 页面资源版本号更新为 `1.33-random-thought-colors`，避免继续使用旧脚本缓存。

## 验证

- `npm.cmd run check` 已通过，30 个测试全部通过。
- 本地预览 `http://127.0.0.1:4181/?v=1.33-random-thought-colors` 已确认：
  - 当前 4 个念头颜色分别为黄、红、粉、橙。
  - 当前念头蓝色数量为 0。
  - 页面中的念头颜色来自 `data-thought-tone` 临时分配，而不是入库字段。
