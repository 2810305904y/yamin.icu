# 个人主页 V1 布局与 V2 待办草稿

文档版本：草稿 V0.1  
整理日期：2026-06-01  
关联参考：`UI/v0/个人网站ui设计.png`

## 当前理解

这个项目不是企业官网，也不是单纯的个人名片页。它更像一个个人中转站：打开以后，访客可以快速看到项目、正在做的方向、公开频道入口，以及一些有点怪但不影响理解的念头。

核心目标：

- 让 `鸦珉.icu` 在第一年作为个人主页主入口。
- 让 `ravenous.top` 作为长期基础设施域名。
- 让 `send.ravenous.top` 承担 Resend 共用发信子域名。
- `ravenous.top` 暂时跳转到 `鸦珉.icu`。
- 邮件、反馈、Resend 等长期系统不要绑定到一年期域名上。

域名最终配置前，需要以域名购买后台里的精确拼写为准，不能只靠语音输入判断。

## 隐私边界

主页可以公开展示：

- 睡前剩几杯 / 睡前咖啡因计算器。
- 破茧：反信息茧房、信息筛查方向的工具。
- 视频粗剪工具：计划中。
- 社交媒体方向 App：计划中，但暂时模糊表达，不写太具体。
- 公开的视频号、YouTube、哔哩哔哩等频道入口。
- 一些奇怪念头、项目想法、公开实验。

主页不公开展示：

- 时间规划器。
- 工作对象、服务关系、时薪。
- 私人规划、私人待办、内部资料。
- Resend API Key、Vercel Token、邮箱密码等任何密钥。

## V1 页面布局

V1 先采用一屏展开式布局，让用户打开页面后基本能看到网站的大部分内容。

桌面端结构：

```txt
┌──────────────────────────────┬──────────────┐
│ 项目区                        │ 正在进行/待办 │
│ 3-6 张项目卡片                 │ 横条列表      │
│                              │              │
├──────────────────────────────┼──────────────┤
│ 奇怪念头区                    │ 自媒体与视频账号│
│ 随机漂浮/出现的短句            │ 链接列表       │
└──────────────────────────────┴──────────────┘
```

移动端结构：

```txt
顶部身份与一句话
项目区
正在进行/待办区
自媒体与视频账号
奇怪念头区
反馈或联系入口
```

移动端不强行保留四象限，因为手机屏幕太窄。更重要的是阅读顺序清楚、按钮好点、不卡。

## V1 分区内容

### 项目区

项目区是页面主角，使用一块一块卡片展示不同项目。每张卡片可以点击跳转到对应域名。

建议卡片字段：

- 项目名。
- 一句话说明。
- 状态标签，例如：已上线、建设中、计划中、实验中。
- 访问链接。
- 一句轻微备注。

首批项目：

- 睡前剩几杯：已上线，跳转到 `coffeesleep.cn`。
- 破茧：建设中，偏反信息茧房/信息筛查。
- 视频粗剪工具：计划中。
- 社交媒体方向 App：计划中，先保持模糊。

### 正在进行 / 待办区

这个区域只展示公开版待办，不展示私人工作或真实时间规划。

形式上使用横条列表，一条一条排列，像一个轻量路线图。

示例方向：

- 整理主页 V1 内容。
- 给项目卡片补真实链接。
- 等长期域名稳定后处理 Resend。
- 研究 V2 的 3D 项目轮。

### 自媒体与视频账号

右下角放公开视频频道入口。先做成链接区，链接可以后补。

候选入口：

- 视频号。
- 今日破茧。
- YouTube。
- 哔哩哔哩。
- 其他以后公开的频道。

### 奇怪念头区

这里放短句、点子、未分类想法。它可以随机漂浮、随机出现，保持一点不稳定感。

原则：

- 短。
- 有一点怪。
- 不影响主功能阅读。
- 不放私人信息。
- 不放需要解释很久的梗。

可用文案方向：

```txt
如果一个东西看起来有点奇怪，它可能还在孵化。
```

```txt
这里不是公司官网，所以不用假装所有东西都有战略意义。
```

```txt
一些认真做的小东西，和一些不太确定为什么存在的东西。
```

## V1 暂不做

- 暂不做复杂后台。
- 暂不做大型 CMS。
- 暂不公开时间规划器。
- 暂不把所有社交媒体 App 想法讲太明白。
- 暂不做 3D 项目轮，以免第一版被动效和兼容性拖慢。
- 暂不把反馈发信绑定到 `鸦珉.icu`。

## V2 待办：3D 项目轮

V2 可以把项目区升级成一个独立的 3D 展示区域。

当前设想：

- 项目卡片变成 3D 空间里的卡片。
- 6 张或更多卡片围成一个立体轮子。
- 用户可以滚动或拖动，让卡片在 3D 中转动。
- 点击当前卡片后进入对应项目。
- 3D 区域和页面其他分区相对独立，避免影响待办区、频道区、奇怪念头区的阅读。

实现时要注意：

- 手机端必须有降级方案，不能因为 3D 导致打不开或很卡。
- 卡片文字必须可读。
- 键盘、触摸、鼠标都要能操作。
- 如果用户开启减少动画，应该关闭复杂转动。
- 先做 V1 的普通卡片内容结构，V2 再复用这些项目数据。

## 推进顺序

1. 先确认 V1 信息架构：四个区块、公开内容、隐私边界。
2. 等用户补充 UI 参考或手绘细节后，整理视觉方向。
3. 再创建网页项目代码，不先套企业官网模板。
4. V1 先做静态首页和项目卡片。
5. 再补反馈或联系入口。
6. 本地检查电脑和手机宽度。
7. 部署到 Vercel。
8. 绑定 `鸦珉.icu` 作为当前主入口。
9. `ravenous.top` 稳定后配置跳转与 `send.ravenous.top`。
10. V1 稳定后，再启动 V2 的 3D 项目轮设计。

## 目前不阻塞的问题

- 视觉细节还没最终确定，可以等用户继续画。
- 频道链接可以先占位，后续补真实链接。
- 社交媒体方向 App 可以先写得模糊，不影响 V1。
- 反馈入口可以先做占位，不急着接 Resend。
