# V1.4.0 主页视觉定稿与固定规则

日期：2026-06-03

## 本次定位

V1.4.0 是当前主页视觉的大版本定稿。它不是新增一个单点功能，而是把前面多轮主页比例、卡片、桌面缩放、念头空间和加载性能调整收束成一个稳定基准。

后续如果没有明确提出“重新设计主页”，默认不要继续重做主页骨架，也不要随意改动项目区卡片、字体、分割线、待办条、频道条和奇怪念头区的基础比例。

## 固定视觉基准

- 背景方向：蓝色天空，较多低矮横向云，云从右往左飘。
- 主体框架：固定 `2400 x 1200` 的 2:1 设计画布，外层整体等比例缩放。
- 桌面窗口适配：小窗口时整张项目地图一起缩小，不让内部文字换行、卡片挤压或分区比例漂移。
- 四区结构：左上项目区、右上正在进行 / 待办区、左下奇怪念头区、右下频道入口区保持当前分割比例。
- 项目区结构：两张竖向大卡片 + 右侧三张横向卡片。三列比例、间距、标题、图标、链接按钮、状态标签以当前版本为准。
- 项目卡片：保留当前圆角、玻璃感、白色卡片质感和阴影；大项目卡片链接按钮不显示右箭头。
- 待办区与频道入口：右上待办条和右下频道条保持当前宽度节奏与居中感。
- 奇怪念头区：保留漂浮标签、碰撞、随机出现/隐藏、随机大小和不换行规则。
- 性能策略：保留顶部轻量加载进度条；线上数据请求短超时；念头物理动画和 Canvas 云层延后到内容出现后启动；移动端和低性能设备降级。

## 当前关键参数

- 设计画布：`2400 x 1200`。
- 缩放策略：`.map-frame` 固定设计尺寸，`.map-viewport` 承接缩放后的外层尺寸。
- 念头区活动盒：`inset: 18px 40px -40px 64px`。
- 念头标签：`width: max-content`，`white-space: nowrap`，避免靠右边界时文字换行。
- 念头初始缩放：`0.96 - 1.36`。
- 念头动态目标缩放：`0.98 - 1.42`。
- 念头可见数量：初始和运行中保持在 `7 - 8` 个附近。

## 后续维护原则

- 新功能优先作为独立模块规划，不默认破坏 V1.4.0 主页基准。
- 如果要改卡片、字体、间距、边界或念头参数，应先说明具体问题和预期截图，不做连带式大改。
- 如果未来进入 3D 项目轮、留言区、账号系统等新阶段，应先保留当前 V1.4 版本作为可回退视觉基准。
