## 版本关系

当前版本号不是三选一，而是逐步推进：

```txt
V0   -> 本地视觉原型，先确认布局、比例、气质和动效
V1   -> 可以正式上线的第一版
V1.5 -> 在 V1 上增强细节，例如更自然的云雾、更多交互、反馈入口
V2   -> 结构升级，例如项目区变成 3D 项目轮
```

本次制作的是 V0，不等于最终上线版。

## 云雾渐变方案

V0 使用最轻的 CSS 方案：

- 多层半透明径向渐变。
- 背景层比页面更大。
- 通过 `cloud-drift` 动画缓慢移动。
- 用很长的动画时间模拟缓慢漂移。

这不是 Canvas / WebGL，也不是实时随机噪声。优点是轻、稳定、容易部署。后续如果需要更自然，可以在 V1.5 尝试 SVG 噪声纹理；V2 再考虑 Canvas 或 WebGL。
