# 个人主页 V1 数据文件化实施记录

文档版本：V1.0 草稿  
整理日期：2026-06-01

## 本次目标

在 V0 视觉原型基础上，先做 V1 的数据文件化基础。

目的不是马上做后台，而是先让这些内容从页面里拆出来：

- 项目区卡片。
- 正在进行 / 待办。
- 奇怪念头。
- 自媒体与视频账号。

这样后续做 `/admin` 编辑页时，可以围绕同一份内容结构继续做。

## 内容编辑方式

当前先通过数据文件维护内容：

```txt
v1/content/site-data.mjs
```

里面分为：

```txt
identity   站点签名
projects   项目区
todos      待办区
thoughts   奇怪念头区
channels   自媒体区
```

每条内容都有 `order` 和 `visible`，为后续排序、隐藏、后台编辑做准备。

## 后台方向

后续 `/admin` 可以复用这些结构：

- 新增内容 -> 往对应列表里增加一条。
- 删除内容 -> 从对应列表移除，或先设为 `visible: false`。
- 排序 -> 修改 `order`。
- 隐藏 -> 修改 `visible`。
- 保存 -> 后续再决定保存到文件、数据库或接口。
