# 个人主页 V1 上线状态与下一阶段计划

文档版本：V1.1 草稿  
整理日期：2026-06-01

## 当前版本定位

当前版本可以视为个人主页 V1：

- 已形成横向四分区页面：项目区、正在进行 / 待办区、奇怪念头区、自媒体与视频账号区。
- 视觉方向已确定为蓝白渐变、轻蓝图分区、带一点悬浮感的项目地图。
- 页面不是企业官网，而是个人项目中转站。
- 项目内容已经从页面结构中拆到数据文件，后续做后台编辑会更容易。

## 线上与域名状态

已上线地址：

```txt
https://yamin-icu.vercel.app/
```

当前自定义域名：

```txt
鸦珉.icu
```

后台配置时使用的 Punycode 形式：

```txt
xn--idyr71g.icu
```

2026-06-01 检查结果：

- `xn--idyr71g.icu` 已解析到 Vercel 相关 IP。
- `https://xn--idyr71g.icu/` 已能返回页面入口，HTTP 状态为 200。
- `www.xn--idyr71g.icu` 当前未查到解析。

建议补充：

- 如果希望 `www.鸦珉.icu` 也能打开，需要在域名 DNS 后台补一条 `www` 记录。
- 主域名能打开后，正式对外分享可以优先使用 `https://鸦珉.icu/`。
- Vercel 当前入口会跳到 `/v1`，后续可以整理成更干净的根路径入口。

## 当前公开内容边界

可以公开：

- 睡前剩几杯 / 睡前咖啡因计算器。
- 破茧。
- 视频粗剪工具作为待办。
- 社交媒体方向 App 作为模糊待办。
- 自媒体与视频账号入口。
- 奇怪念头区的短句。

不公开：

- 时间规划器。
- 工作对象、服务关系、时薪、私人计划细节。
- 任何不适合被搜索引擎长期记录的个人信息。

## 当前内容编辑方式

V1 暂时通过数据文件维护内容：

```txt
v1/content/site-data.mjs
```

主要字段：

- `projects`：项目区卡片。
- `todos`：正在进行 / 待办区。
- `thoughts`：奇怪念头区。
- `channels`：自媒体与视频账号。
- `identity`：左下角站点签名。

每条内容尽量保留：

- `order`：排序。
- `visible`：是否显示。

这样以后做后台时，可以直接复用这套内容结构。

## 后续工作方式

建议保持这个节奏：

1. 先本地改页面和文案。
2. 用本地地址预览。
3. 用户确认视觉和内容。
4. 运行检查。
5. 提交到 Git。
6. 推送 GitHub。
7. 由 Vercel 自动部署。
8. 部署后再检查线上域名。

说明：

- AGENTS.md 与 Memory.md 只记录长期有效规则，不记录每天做了什么。
- 每次阶段性进展写入 `项目进度` 文件夹。
- 大改前可以新开草稿文档，小改可以直接记录到对应阶段文档。

## 下一阶段路线

### V1.1：收尾与稳定

目标：让当前页面适合正式分享。

- 补齐 `www.鸦珉.icu` 的 DNS 记录。
- 整理 Vercel 根路径，让访问 `/` 时尽量不暴露 `/v1`。
- 再做一次桌面端截图验收。
- 做一次手机端基础验收，至少保证不会完全挤坏。
- 修正 README 中的上线地址和域名说明。

### V1.2：内容编辑后台雏形

目标：让你可以不用改代码就编辑主页内容。

建议先做一个简化后台：

```txt
/admin
```

第一版后台只做：

- 查看项目卡片列表。
- 新增、隐藏、排序项目卡片。
- 编辑待办区标题和进度。
- 新增、隐藏、排序奇怪念头。
- 编辑频道链接。

登录方式先不要做复杂：

- 可以先用一个简单密码保护。
- 等后续需要多人或更严肃权限时，再接正式账号系统。

### V1.3：反馈通道

目标：让主页能接收留言或反馈。

前提：

- `ravenous.top` 稳定。
- `send.ravenous.top` 在 Resend 验证通过。

建议：

- 不把发信系统绑到 `鸦珉.icu`。
- 反馈邮件走 `send.ravenous.top`。
- 主页只负责展示和提交反馈。

### V2：3D 项目轮

目标：把项目区升级为独立的 3D 交互区域。

暂存想法：

- 项目卡片像一个立体轮子一样排列。
- 可以横向或滚轮滚动。
- 卡片数量可以从 6 张扩展到更多。
- 3D 区域可以和其他页面区域相对独立。

V2 不建议现在急着做。当前应先让 V1 稳定、可维护、可持续更新。
