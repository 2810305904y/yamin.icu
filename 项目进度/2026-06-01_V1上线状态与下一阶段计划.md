# 个人主页 V1 上线状态与下一阶段计划

文档版本：V1.1 草稿  
整理日期：2026-06-01

## 当前版本定位

当前版本可以视为个人主页 V1：

- 已形成横向四分区页面：项目区、正在进行 / 待办区、奇怪念头区、自媒体与视频账号区。
- 视觉方向已确定为蓝白渐变、轻蓝图分区、带一点悬浮感的项目地图。
- 页面不是企业官网，而是个人项目中转站。
- 项目内容已经从页面结构中拆到数据文件，后续做后台编辑会更容易。

## 线上与域名状态

已上线地址：

```txt
https://yamin-icu.vercel.app/
```

当前自定义域名：

```txt
鸦珉.icu
```

后台配置时使用的 Punycode 形式：

```txt
xn--idyr71g.icu
```

2026-06-01 检查结果：

- `xn--idyr71g.icu` 已解析到 Vercel 相关 IP。
- `https://xn--idyr71g.icu/` 已能返回页面入口，HTTP 状态为 200。

建议补充：

- 如果希望 `www.鸦珉.icu` 也能打开，需要在域名 DNS 后台补一条 `www` 记录。
- 主域名能打开后，正式对外分享可以优先使用 `https://鸦珉.icu/`。
- Vercel 当前入口会跳到 `/v1`，后续可以整理成更干净的根路径入口。

## 当前公开内容边界

可以公开：

- 睡前剩几杯 / 睡前咖啡因计算器。
- 破茧。
- 视频粗剪工具作为待办。
- 社交媒体方向 App 作为模糊待办。
- 自媒体与视频账号入口。
- 奇怪念头区的短句。

不公开：

- 时间规划器。
- 工作对象、服务关系、时薪、私人计划细节。
- 任何不适合被搜索引擎长期记录的个人信息。

## 当前内容编辑方式

V1 暂时通过数据文件维护内容：

```txt
v1/content/site-data.mjs
```

主要字段：

- `projects`：项目区卡片。
- `todos`：正在进行 / 待办区。
- `thoughts`：奇怪念头区。
- `channels`：自媒体与视频账号。
- `identity`：左下角站点签名。

每条内容尽量保留：

- `order`：排序。
- `visible`：是否显示。

这样以后做后台时，可以直接复用这套内容结构。

## 后续工作方式

建议保持这个节奏：

1. 先本地改页面和文案。
2. 用本地地址预览。
3. 用户确认视觉和内容。
4. 运行检查。
5. 提交到 Git。
6. 推送 GitHub。
7. 由 Vercel 自动部署。
8. 部署后再检查线上域名。

说明：

- AGENTS.md 与 Memory.md 只记录长期有效规则，不记录每天做了什么。
- 每次阶段性进展写入 `项目进度` 文件夹。
- 大改前可以新开草稿文档，小改可以直接记录到对应阶段文档。

目标：开一个专门用于测试服的子域名，避免未定稿内容直接推到主站。

测试服目标域名：

```txt

```

后台配置时使用的 Punycode 形式：

```txt
test.xn--idyr71g.icu
```

当前状态（2026-06-05）：

- Vercel 已创建独立测试项目：`yamin-icu-test`。
- 当前代码已部署到测试项目，临时地址为 `https://yamin-icu-test.vercel.app/`。
- `test.xn--idyr71g.icu` 已绑定到 Vercel 测试项目。
- Vercel 侧检查结果：测试域名还缺 DNS 记录。
- 域名 DNS 后台需要新增推荐记录：`A test.xn--idyr71g.icu 76.76.21.21`。
- 本地 `.vercel` 链接已恢复到主站项目 `yamin-icu`，避免后续误部署到测试项目。

用途：

- `鸦珉.icu` 保持稳定版，只放已经确认可以公开的内容。
- `test.鸦珉.icu` 用作测试服，专门预览手机端、3D 项目区、新交互、新视觉等未定稿内容。
- 测试服确认满意后，再合并或推送到主站。

后续实施：

- 在域名 DNS 后台新增 `test` 子域名解析，等待 Vercel 自动验证。
- 明确测试服内容发布流程：先部署到 `yamin-icu-test`，确认后再推主站。
- 确认测试服和主站的数据、环境变量、后台保存权限不要互相误伤。

### V1.5：手机端竖版布局进展

当前进展：

- 手机端已从“整张横版地图缩放”改为竖版长卷轴布局。
- 手机端展示顺序调整为：项目区、施工中、怪念头、自媒体入口。
- 桌面端继续保持 V1.4 固定 `2400 x 1200` 横版项目地图，不跟随手机端重排。
- 手机端已关闭云层背景动画，优先降低真实手机上的卡顿感。
- 手机端项目卡片已改为更紧凑的横向信息结构，大图标已移除。
- 手机端顶部站点标识已移动到页面最上方，并放大为主页 logo。
- 手机端怪念头区域已放大到独立碰撞池，并保持 7 个左右的初始可见标签。
- V1.5.6 已针对“标签堆成竖线”的反馈调整：怪念头池左右各外扩 `12px`，碰撞安全边距从 `56px` 改为 `24px`，长标签保留 `48px` 安全空间，让标签有更明显的左右游走范围。

后续计划：

- 手机端继续按真实截图反馈小步微调，不一次性重做整套 UI。
- 重点观察怪念头区在不同手机宽度下是否仍会聚成竖线；如果还偏挤，再考虑减少同时可见数量、降低长标签最大宽度，或让标签初始分布更分散。
- 项目区、自媒体区和施工中区域暂时以当前 V1.5.6 为基准，只在出现明显阅读或触控问题时再调。
- 测试区子域名 DNS 生效后，手机端新交互优先推到测试服确认，再合并到主站。

### V1.2：内容编辑后台雏形

目标：让你可以不用改代码就编辑主页内容。

建议先做一个简化后台：

```txt
/admin
```

第一版后台只做：

- 查看项目卡片列表。
- 新增、隐藏、排序项目卡片。
- 编辑待办区标题和进度。
- 新增、隐藏、排序奇怪念头。
- 编辑频道链接。

近期视觉动效补充：

- 奇怪念头区后续升级为“念头空间”：随机选取部分念头作为漂浮卡片显示。
- 每张念头卡片拥有独立碰撞体积，在区域内随机运动，彼此碰撞时弹开。
- 念头可每隔 3 到 5 秒随机出现或隐藏；隐藏后移除碰撞体积，不再参与碰撞。
- 详细记录见 `项目进度/2026-06-01_V1数据文件化实施记录.md` 的“后续动效需求”。

登录方式先不要做复杂：

- 可以先用一个简单密码保护。
- 等后续需要多人或更严肃权限时，再接正式账号系统。
