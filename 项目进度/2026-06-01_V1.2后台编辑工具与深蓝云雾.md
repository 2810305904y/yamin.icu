# V1.2 后台编辑工具与深蓝云雾

文档版本：V1.2 草稿  
整理日期：2026-06-01

## 本阶段目标

V1.2 做两件事：

- 新增一个 `/admin` 内容编辑台。
- 把首页背景的云雾感做得更明显，加入更深一点的蓝色流动层。

## `/admin` 当前定位

当前 `/admin` 是静态编辑工具，不是最终数据库后台。

它可以：

- 编辑项目区卡片。
- 编辑正在进行 / 待办区。
- 编辑奇怪念头区。
- 编辑自媒体与视频账号入口。
- 新增、删除、上移、下移、隐藏内容。
- 在右侧看到实时预览。
- 把草稿保存在当前浏览器。
- 下载新的 `site-data.mjs` 数据文件。

它暂时不能：

- 直接把修改写入线上网站。
- 多设备同步草稿。
- 提供真正的账号登录。

原因：

当前网站仍然是静态部署。静态页面本身不能直接改服务器上的文件。  
如果要做到“点保存就更新线上网站”，后续需要接入存储和身份验证。

## 后续真正后台方向

下一步可选路线：

1. 继续保持轻量：后台生成数据文件，由 Codex 帮忙合并并发布。
2. 接数据库：例如 Supabase，用登录保护 `/admin`，保存后首页读取数据库。
3. 接 GitHub 写文件：后台保存时直接改 GitHub 仓库文件，再触发 Vercel 部署。

当前推荐先用第 1 种，等内容编辑流程稳定后，再升级到第 2 或第 3 种。

## 深蓝云雾背景

已调整：

- 首页背景仍然保持蓝白基调。
- 增加了更深的蓝色径向云雾。
- 云雾层继续缓慢漂移。
- 没有改成暗黑模式，避免偏离当前蓝图感。

注意：

- 这个视觉效果主要服务桌面端。
- 手机端暂时不做降级，也不作为本阶段重点。

## 本阶段检查项

- `/` 仍然直接显示首页，不跳 `/v1`。
- `/admin` 可以打开编辑台。
- `npm.cmd run check` 应通过。
- 后台编辑不会影响线上内容，除非后续手动合并导出的数据。
