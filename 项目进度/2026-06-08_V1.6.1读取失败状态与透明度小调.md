# V1.6.1 读取失败状态与透明度小调

日期：2026-06-08

## 目标

修正 V1.6.0 加载遮罩在测试服静态回退时仍显示“读取完成”的问题。读取层需要区分真实读取成功和读取失败 / 静态回退。

## 调整

- 资源号更新为 `1.6.1-loading-failure-state`。
- 只有成功读取线上数据时，读取层才显示“读取完成”并快速淡出。
- 如果接口失败、超时、数据库不可用，或测试服回退到静态数据，读取层显示“读取失败，显示备用页面”。
- 失败状态下进度条停在未满格状态，不再自动推满。
- 失败状态展示后更快露出备用主页，页面上的读取失败提示和 `THIS IS FINE` 备用背景继续保留。
- 加载面板和整体遮罩透明度降低，让读取层更轻、更透。

## 状态

- `npm.cmd run check` 已通过。
- 已部署到测试服 `https://test.xn--idyr71g.icu/`。
- 测试服首页已确认包含 `1.6.1-loading-failure-state`。
- 测试服脚本已确认包含“读取失败，显示备用页面”和 `finishLoadingScreen(!shouldWarn)`。
- 测试服 CSS 已确认包含失败进度条状态和更透明的 `rgba(244, 250, 255, 0.52)` 面板背景。
- 测试服 `/api/site-data` 当前仍返回 `source: static`，因此会触发读取失败状态。
