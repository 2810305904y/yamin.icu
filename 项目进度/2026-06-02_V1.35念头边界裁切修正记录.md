# 2026-06-02 V1.35 念头边界裁切修正记录

## 版本定位

V1.35 是 V1.2 阶段的视觉小修版本，重点处理奇怪念头标签碰到空间边界时出现轻微裁切边缘的问题。

## 本次确定内容

- 保持 V1.34 的奇怪念头空间外框尺寸不变。
- 将念头物理边界的内部安全距离从 `8px` 增加到 `40px`。
- 空间不足时自动取可用的最大安全距离，避免小窗口下安全距离退回到 `0px`。
- 标签会在更早的位置反弹，让标签本体、旋转外框和阴影都尽量不贴到 `.thought-space` 的裁切边缘。
- 首页与 V1 页面资源版本号更新为 `1.35-thought-edge-buffer`，避免继续使用旧脚本缓存。

## 验证

- `npm.cmd run check` 已通过：31 项测试全部通过。
- 本地预览已检查：在 `2048 x 1120` 宽屏视口下，奇怪念头区宽度约 `1158px`，当前可见标签距离裁切边的最小可见间距约 `43px`，靠近边缘时不再直接贴到可见边界。
