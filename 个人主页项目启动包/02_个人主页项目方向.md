# 个人主页项目方向

整理日期：2026-06-01

## 项目目标

准备在一个新的根文件夹里开启个人主页项目。这个个人主页不只是普通名片页，也可以成为用户未来多个小工具、实验页面、产品入口和个人表达的中心。

候选主域名：

```txt
revenge.top
```

如果实际域名不同，需要统一替换。

## 推荐定位

这个站点可以被理解为：

```txt
个人主页 + 项目入口 + 工具集合 + 轻微怪东西陈列柜
```

它不需要一开始就做得很复杂。第一版最重要的是：

- 打开就知道“这是你的地方”。
- 可以看到你已经做过或正在做的项目。
- 可以跳到睡前咖啡因计算器、破茧等项目。
- 以后可以挂临时实验、玩具页面、奇怪想法。
- 可以接入一个简单反馈或联系入口。

## 首屏建议

首屏不要做成过度商业化的营销页。更适合做一个有个人气质的主页：

- 有清楚的名字或代号。
- 有一句短而有记忆点的话。
- 有几个明确入口：项目、工具、文字、联系。
- 视觉上可以有一点怪、有一点冷幽默，但不要牺牲可读性。

可选方向：

```txt
这里不是公司官网。
这里是一些工具、想法、试验品和我暂时还没想好怎么分类的东西。
```

或者更短：

```txt
一些认真做的小东西，和一些不太确定为什么存在的东西。
```

## 页面结构建议

第一版可以只做一个首页：

```txt
顶部：名字 / 简短介绍 / 导航
第一屏：一句个人表达 + 主要入口
项目区：睡前剩几杯、破茧、其他项目
玩具区：短期域名、实验页面、临时页面
关于区：你在做什么、为什么做
联系/反馈区：邮箱或反馈按钮
```

## 项目卡片建议

项目卡片里可以包含：

- 项目名
- 一句话解释
- 当前状态
- 访问链接
- 很短的备注

示例：

```txt
睡前剩几杯
输入喝咖啡和睡觉时间，估算睡前体内还剩多少杯咖啡。
状态：已上线
```

```txt
破茧
另一个正在接入反馈通道的项目。
状态：建设中
```

## 域名使用建议

长期域名：

```txt
revenge.top
```

用于：

- 个人主页
- 长期项目索引
- Resend 发信子域名
- 未来稳定入口

短期玩具域名：

```txt
雅名.icu
```

用于：

- 实验页面
- 一年期活动页
- 视觉玩法
- 跳转页
- 不怕丢的东西

## 第一版不要做的事

- 不要一开始就做复杂后台。
- 不要先做大型 CMS。
- 不要把所有项目都强行塞进同一种模板。
- 不要把 Resend 发信绑定到短期玩具域名。
- 不要为了炫技影响手机端打开速度。

## 推荐第一版完成标准

- 电脑和手机都能正常打开。
- 首页能清楚表达“这是你的个人入口”。
- 至少有 2 个项目入口。
- 有一个联系或反馈入口。
- 代码推送后 Vercel 能自动部署。
- 文案、进度和备份都在固定文件夹里留档。
