# 个人主页项目启动包使用说明

整理日期：2026-06-01

用途：把当前对话里已经明确的背景、偏好、域名计划、反馈通道方案和协作方式整理成可复用 Markdown。之后开启新的个人主页项目时，可以把这些文件拖进新对话，让新对话快速理解上下文。

## 建议使用方式

1. 新建一个新的项目根目录，例如：

   ```txt
   D:\Codex Project\个人主页
   ```

2. 把本文件夹里的 Markdown 复制或拖入新对话。

3. 如果新项目需要长期规则，再从这些文件里提炼出新的 `AGENTS.md`，不要直接把所有历史背景塞进 `AGENTS.md`。

4. 如果新项目也接入反馈通道，优先参考：

   ```txt
   04_反馈通道与Resend复用方案.md
   ```

## 文件说明

- `01_当前上下文_域名与项目状态.md`：当前已有项目、域名、Resend、Vercel 的整体状态。
- `02_个人主页项目方向.md`：新个人主页可以怎么做，哪些内容适合放进去。
- `03_协作偏好与工作流.md`：和 Codex 协作时的行为模式、偏好、版本和归档方式。
- `04_反馈通道与Resend复用方案.md`：多个项目共用一个 Resend verified domain 的方案。
- `05_文案气质与幽默风格.md`：用户喜欢的表达方式、幽默方向和文案边界。

## 关键信息

长期基础域名候选：

```txt
revenge.top
```

注意：如果实际购买的域名不是 `revenge.top`，后续所有文档里的 `revenge.top` 都应替换为真实域名。

短期玩具域名候选：

```txt
雅名.icu
```

反馈接收邮箱：

```txt
2810305904@qq.com
```

不要把 Resend API Key、Vercel Token、邮箱登录密码等密钥写入这些 Markdown，也不要直接发到普通对话里。
