## 已有项目

当前主要项目是“睡前咖啡因计算器”，线上域名：

```txt
https://coffeesleep.cn/
```

项目核心功能：

- 输入喝咖啡时间。
- 输入睡觉时间。
- 估算睡前体内还剩多少杯咖啡。
- 已经做过移动端兼容处理，解决过旧浏览器脚本不运行、图标异常、音效延迟、滚动过渡等问题。
- 已经接入反馈窗口，用户可以提交反馈，服务端通过 Resend 发邮件到用户指定邮箱。

## 已跑通的反馈通道

当前“睡前咖啡因计算器”已经跑通过：

```txt
前端反馈窗口
-> Vercel Serverless API
-> Resend
-> 2810305904@qq.com
```

已实现的安全与限制：

- 内容必填。
- 有隐藏字段防简单机器人。
- 同一个 IP 一分钟最多提交 2 次。
- 同一个 IP 一天最多提交 4 次。
- 这些限制是 Vercel 函数内存里的轻量限制，不是数据库级别的强限制。

## 当前遇到的新问题

Resend 免费版通常只能验证 1 个 custom domain。之前“睡前咖啡因计算器”已经用 `coffeesleep.cn` 跑通过反馈邮件。

但现在还需要让另一个项目“破茧”也接入反馈通道：

```txt
https://pojian.space/
```

用户不希望多个项目在业务身份上混在一起，也不希望一个产品域名关闭后影响其他项目，所以希望把 Resend 的唯一 verified domain 抽离成一个中立、长期、共享的基础设施域名。

## 域名规划

长期基础域名候选：

```txt
revenge.top
```

这个域名的定位：

- 长期续费便宜。
- 可以做个人主页。
- 可以作为多个项目的基础设施域名。
- 可以提供 Resend 共用发信子域名。

建议结构：

```txt
revenge.top              个人主页
www.revenge.top          个人主页备用入口
send.revenge.top         Resend 共用发信域名
tools.revenge.top        工具集合或项目索引，可选
```

短期玩具域名候选：

```txt
雅名.icu
```

这个域名的定位：

- 首年很便宜。
- 可以用来玩一年。
- 可以挂实验页面、好玩的个人入口、临时项目。
- 不建议绑定重要系统，例如 Resend 发信、长期反馈通道、长期登录入口。

## 核心判断规则

```txt
能丢的东西 -> 放玩具域名
不能丢的东西 -> 放长期域名
邮件 / Resend / 反馈通道 -> 只放长期域名
```

## 域名注册当前状态

用户提到域名平台显示注册或审核还没有完成。此时不应急着填 Resend 或 Vercel。

推荐顺序：

1. 等域名注册、实名、审核状态稳定。
2. 再决定根域名是否绑定 Vercel。
3. 再在 Resend 添加 `send.revenge.top`。
4. 再去阿里云 DNS 添加 Resend 给出的解析记录。
5. Resend 验证通过后，再修改各个项目的 Vercel 环境变量。
