# 文案气质与幽默风格

整理日期：2026-06-01

## 总体气质

用户喜欢的表达不是传统互联网产品那种过度正经、过度营销、过度“我们致力于”的语气。

更合适的气质是：

- 有一点怪。
- 有一点认真。
- 有一点冷幽默。
- 像真实的人在说话。
- 不装企业。
- 不装高深。
- 可以可爱，但不要幼稚。
- 可以荒诞，但不要影响功能理解。

## 已经被用户接受过的表达方向

反馈按钮附近：

```txt
有什么想法给我？请狂戳上面这个按钮↑
```

反馈框占位：

```txt
请不要发送暗恋情书。
```

反馈成功：

```txt
我马上就会看到您的反馈啦~
```

这些文案的共同点：

- 轻松。
- 有一点出人意料。
- 不妨碍用户理解功能。
- 不是为了搞笑而搞笑。

## 适合个人主页的文案方向

个人主页可以带一点“私人仓库”的感觉：

```txt
一些认真做的小东西，和一些不太确定为什么存在的东西。
```

```txt
这里放着我的工具、想法、实验品，以及一些暂时还没有分类成功的东西。
```

```txt
如果一个东西看起来有点奇怪，它可能还在孵化。
```

```txt
这里不是公司官网，所以不用假装所有东西都有战略意义。
```

## 不太适合的文案

不建议使用：

```txt
打造全新的数字化个人品牌矩阵。
```

```txt
以创新驱动增长，以体验赋能未来。
```

```txt
欢迎来到我的元宇宙个人生态入口。
```

这些表达太像模板，和用户当前气质不匹配。

## 幽默边界

可以有：

- 轻微自嘲。
- 生活化吐槽。
- 意外但温和的提醒。
- 和工具功能有关的小玩笑。

慎用：

- 太攻击性的表达。
- 太私人化、让陌生访客不适的表达。
- 太密集的梗。
- 需要解释才懂的梗。

## 产品文案原则

先保证用户知道能做什么，再放一点好玩。

推荐结构：

```txt
清楚功能 + 一点点怪
```

示例：

```txt
反馈会发到我的邮箱。请不要发送暗恋情书。
```

比下面这种更好：

```txt
请在此处释放您被现实挤压过的灵魂碎片。
```

原因：后者虽然有趣，但用户不一定知道这里到底要填什么。

## 个人主页视觉气质建议

视觉上可以：

- 清爽。
- 有一点实验感。
- 留白足够。
- 不要太企业官网。
- 不要全站一个颜色糊到底。
- 可以有小图标、小标签、小状态。
- 可以给项目卡片加一点“状态感”，例如：已上线、建设中、玩具、一年期实验。

## 一句话方向

如果新项目开头需要一句总方向，可以先用：

```txt
这是一个个人主页，也是一张稍微不太正经的项目地图。
```

或者：

```txt
我把一些工具、项目和奇怪想法放在这里，方便它们不要走丢。
```
